# Paradise Nursery - E-Commerce Plant Shopping Application

An interactive e-commerce web application built with React and Redux Toolkit for browsing, selecting, and purchasing houseplants.

## Features
- Landing page with company background and call-to-action button.
- Product catalog with categorized plants, pricing, thumbnail images, and "Add to Cart" state.
- Global cart state managed via Redux Toolkit.
- Dynamic cart drawer showing itemized breakdown, total cost, quantity controls, and checkout flow.
